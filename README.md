## 住宅 IP 和机房 IP，差的到底是什么

普通台湾 VPS 给你的 IP 来自机房或云服务商的地址池，WHOIS 记录指向托管商，风控引擎一眼就能归类成“商业托管”。住宅 IP 来自 HiNet 这类家宽运营商的 PPPoE 拨号池，在 IP 库里被识别为家庭宽带用户，行为特征更接近台北某间公寓里的普通上网连接。

三个概念值得单独拎出来：

**ASN。** 中华电信 HiNet 的 ASN 是 AS3462，这是台湾最大的家用宽带运营商。丽萨主机这条线用的是 HiNet 家宽 IP，不是机房段，这是它和同站“台湾原生 IP VPS”最本质的差别。

**双 ISP。** 官方套餐名里带“双 ISP”，指的是 IP 在 ISP 层面带有更强的家宽属性，让它在风控模型里更难被归类成托管 IP。具体实现方式各方说法不一，你不需要纠结技术细节，只要知道它的目的是让 IP 更像真实家庭宽带就够了。

**动态 IP。** 这条线的 IP 是动态的，被平台标记之后可以换一个干净的继续用，不用整台机器从头再来。默认分配的 IP 在你不主动更换时是相对稳定的，不是每隔几小时自动轮换。

一句话区分：**原生 IP 解决“是不是台湾”的问题，住宅 IP 解决“像不像台湾家庭用户”的问题。** 两者都能解锁动画疯、Netflix 台区、Disney+，但只有住宅 IP 在账号风控场景里更抗打。

### 拿到机器后怎么自查 IP 质量

别只看商家页面写的“住宅”两个字。开机后用 IP 检测工具查三件事：ASN 是不是 AS3462 这类家宽运营商、使用者类型标的是 Residential 还是 Datacenter、有没有命中匿名代理和黑名单库。第三方检测里出现过这样的结果：某个台湾 IP 被评为住宅类型、Cable/DSL、独立性高，同时标注非匿名 VPN、非机房代理、非黑名单、非滥用节点、非 TOR。这说明检测项是可以逐条看的，不是玄学。

顺带说一句，住宅 IP 的纯净度不是永久保证。用久了被平台标记属于正常现象，这正是动态 IP 可以切换的价值所在。

## 大陆访问：官方自己都说要中转

丽萨主机在台湾所有产品线页面上都挂了一句话：非大陆直连优化网络，建议通过香港或日本线路中转使用。

这不是客套话。第三方测试的口径是：电信走 163 普通直连，联通走 AS4837，移动走 CMI；电信回程经上海、广东入口，延迟在 60–190ms 之间浮动，联通和部分移动节点能压到 50ms 以内，整体平均延迟 100ms 出头。晚高峰丢包会有波动。另一组针对 BGP 线路的测试给出的区间是 80–120ms。两组的测试对象和时段不同，不必强行合成一个精确数字，你只要知道这条线大致落在 80–190ms 区间、平均 100ms 上下，具体看你所在的运营商和时段。

对 TikTok 运营、电商后台登录这种非实时业务，这个延迟完全够用。指望它像 CN2 GIA 那样大陆直连低延迟，会失望。

电信用户基本需要中转。做法是再买一台香港或日本的优化线路 VPS 做前端，回程走优化线路，再把流量转发到台湾住宅 VDS。终端出口仍然是台湾住宅 IP，风控视角不受影响。联通和部分移动节点直连也能跑，官方页面也提到过联通和部分地区移动直连速度不错。

另外官方明确建议开启 BBR。这条线不是大陆优化线路，拥塞控制用 BBR 对实际吞吐的改善很明显，尤其是中转场景下。

**1G 内存那档能装 Windows 吗？**
不建议，会很吃力。2G 内存及以上（300Mbps 和 500Mbps 档）支持安装 Windows。

**和同门的台湾原生 IP 线到底差在哪？**

**能退款吗？**
48 小时内可以申请，但只退网站余额，不原路退回。这是特殊产品的条款，下单前要接受。

**和 IPdodo 这类代理 IP 服务有什么区别？**
代理给你的是一个出口，按月或按流量计费，便宜；VDS 给你的是一台完整机器，能装系统、跑客户端、挂脚本。只登网页后台用代理就够，需要机器本身才选 VDS。
